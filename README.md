# ft-1

This is a calculator app that I build to experiment with modern web dev tools. It's a Svelte app, using Bun, Vite, Less, and TypeScript. The app itself supports basic arithmetic, and theme switching with localStorage persistence.

This app has both unit tests and end to end tests using Vitest, test-framework, and Playwright to ensure correctness.

Start a development server with `bun run dev`, test with `bun run test` and deploy for production with `bun run build`
